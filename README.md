# Лабораторная работа: Усеченный правильный тетраэдр (Вариант 4)

## Начало работы

### 1. Подготовка репозитория

Если вы еще этого не сделали, клонируйте репозиторий или убедитесь, что вы находитесь в корневой папке проекта:
```bash
git clone https://github.com/saparyp/CG_1lab_var_4
cd CG_1lab_var_4
```

### 2. Конфигурация проекта

Выполните одну из следующих команд CMake для загрузки зависимостей и генерации файлов сборки. Выберите пресет, соответствующий вашему компилятору:

```bash
cmake --preset msvc-debug  # для Windows (Visual Studio / MSVC)
cmake --preset mingw-debug # для Windows (MinGW)
cmake --preset debug       # для GNU/Linux (GCC/Clang)
```
*(Если вы хотите собрать релизную версию, замените `debug` на `release`)*.

### 3. Сборка проекта

Для сборки используйте команду ниже. Если вы выбрали пресет отладки, файлы будут помещены в директорию `build-debug`.

```bash
cmake --build build-debug --parallel
```
*(Для релизной сборки используйте `cmake --build build-release --parallel`)*

### 4. Запуск приложения

** Убедитесь, что ваша **рабочая директория** установлена в **корень проекта** (туда, где находятся этот `README.md` и `CMakeLists.txt`). В противном случае программа не сможет найти скомпилированные шейдеры (`.spv` файлы), так как в коде используются относительные пути.

Запустите исполняемый файл из корня проекта:

```bash
# Для сборок MSVC (Visual Studio):
./build-debug/Debug/vulkan-starter-app.exe

# Для сборок MinGW:
./build-debug/vulkan-starter-app.exe
```

## Реализованные функции и управление (ImGui)

1. **Переключение матрицы проекции**: Чекбокс позволяет мгновенно переключаться между перспективной (`glm::perspective`) и ортографической (`glm::ortho`) проекцией.
2. **Трансформации фигуры**: Добавлены ползунки (`SliderFloat3`) для независимого изменения позиции (X, Y, Z), поворота (в градусах) и масштаба (растяжения) фигуры в реальном времени.
3. **Сложная анимация**: Реализована параметрическая траектория движения (фигура Лиссажу с колебаниями по оси Y и вращением). Доступны элементы интерфейса для:
   - Включения/паузы анимации (`Checkbox`).
   - Изменения скорости воспроизведения (`Speed`).
   - Изменения радиуса траектории (`Radius`).
4. **Изменение цвета фигуры**: Используется виджет `ColorEdit4` для выбора базового цвета (Base Color), который применяется ко всей фигуре.
5. **Процедурная раскраска вершин**: Цвет каждой вершины вычисляется алгоритмически на основе её локальных координат (создает 3D-градиент). При рендеринге этот процедурный цвет умножается на базовый цвет, выбранный в интерфейсе (п. 4), что позволяет гибко управлять итоговой палитрой.
